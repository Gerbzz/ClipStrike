# Source scope and reproducibility

- Existing public history starts at `Gerbzz/Clipstrike` main commit `fdf2f6ac8828374b803577ae1f6b310b73860075`; DemoStrike pins that exact Git revision for `clipstrike-core`, `clipstrike-ui` and `clipstrike-media`. This candidate is a normal descendant; the historical commit remains necessary.
- Source is selected from the verified ClipStrike migration over FilmCraft commit `2ff3f5e266838700c292a35aaf762e3d4dcef980`: the actual `apps/filmcraft` native editor and 43 required donor crates, plus `tts-text` for the declared optional neural-voices feature. No DemoStrike source, FilmCraft CLI/web app, donor golden screenshots or automation server is copied.
- The seven small bundled fonts retain their OFL texts and attribution sidecars. The original donor `LICENSE-MIT`, `LICENSE-APACHE`, and `NOTICE` are retained. `ATTRIBUTION.md` lists only bundled items. ArtCraft trademarks, upstream app icons, promotional screenshots and captured media are excluded. ClipStrike's own wordmark/window icon are code-drawn and do not assert a first-party license grant.
- Packaging edits: reduce root workspace membership/dependencies, remove `license.workspace = true` from the first-party app manifest, remove an unsupported first-party MIT/Apache assertion from Windows version resources, and regenerate `Cargo.lock` offline for the selected members. On Windows, the candidate and original app resolve the **same 282 package name/version/source tuples**; no dependency version changed.
- The original test fixture derived from a real HE match is excluded. It is replaced by `synthetic-chronological.cstrike` with invented media names, no capture provenance, and invented 60-fps cut values; importer assertions use those new values. The changed test has not been run in this standalone candidate.
- No user project, raw match fact, local media path, capture recording, database, log, credential, build cache, executable or machine-specific state is packaged. The source-generated demo is shown only in a reviewed PNG. The source-only audit and locked Windows metadata pass; an exact-public-source offline desktop build also completed. Full tests, a clean-cache build, and native interaction review are pending.

The donor license covers the copied FilmCraft code, not the first-party ClipStrike changes. Native input, speaker sync and broad media compatibility remain outside the frozen control-based checkpoint.
