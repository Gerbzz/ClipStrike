# 🎬 OpenShot Video Editor — Full Feature List (2026)

This document outlines the complete feature set of OpenShot Video Editor (v3.4.x), serving as the benchmark for the ClipStrike clone.

## 1. Core Architecture & UI
- **Cross-Platform:** Windows, macOS, Linux, and Chrome OS support.
- **Easy-to-use Interface:** Minimalist design, drag-and-drop workflow.
- **Unlimited Tracks:** No limit on the number of layers/tracks.
- **Desktop Integration:** Native drag-and-drop from OS file explorers.
- **Multi-Language Support:** Localized in 70+ languages.
- **Real-time Previews:** Fast timeline playback and scrubbing.

## 2. Timeline & Editing
- **Interactive Trimming & Slicing:** Razor tool and edge-handle trimming.
- **Magnetic Snapping:** Clips snap to edges, playhead, and markers.
- **Clip Manipulation:** Move, copy, paste, and delete clips across tracks.
- **Transitions:** Over 400+ built-in transitions with real-time previews.
- **Time Effects:** Speed up (up to 16x), slow down (1/16x), or reverse clips.
- **Frame Stepping:** Accurate frame-by-frame navigation.
- **Markers:** Add, label, and jump between timeline markers.

## 3. Animation & Keyframes
- **Curve-based Framework:** Powerful animation engine for any property.
- **Interpolation Modes:** Linear, Bézier, and Constant (hold).
- **Animated Properties:** Position, Scale, Rotation, Alpha, Volume, etc.
- **Draggable Keyframes:** Visual keyframe markers on the timeline for easy repositioning.

## 4. Video Effects (Compute/FFmpeg)
- **Essential Effects:** Brightness, Contrast, Saturation, Gamma, Hue, Greyscale.
- **Professional Tools:**
    - **Chroma Key:** High-quality green/blue screen removal.
    - **Color Map (LUT):** Support for 1D & 3D .cube LUT files.
    - **Sharpen:** Detail enhancement with High Pass mode.
    - **Blur:** Various Gaussian and box blur presets.
- **Artistic Effects:** Lens Flare, Outline, Pixelate, Negative.
- **Distortion Tools:** Fisheye removal, Spherical Projection (360/180 conversion).

## 5. Audio Editing
- **Waveform Display:** Visual audio waveforms on timeline clips.
- **Audio Mixing:** Volume levels, panning, and channel mapping.
- **Split Audio:** Extract audio from video into a separate clip.
- **Audio Effects:** Echo, Delay, Distortion, and Robotization.

## 6. Titles & Overlays
- **Static Titles:** Simple SVG-based text overlays.
- **3D Animated Titles:** Powered by Blender integration (20+ templates).
- **Vector Support:** Support for SVG titles and watermarks.
- **External Bridge:** "Edit in Inkscape" and "Edit in Blender" right-click options.

## 7. Media Support & Export
- **FFmpeg Powered:** Support for almost all video, audio, and image formats.
- **Image Sequences:** Import numbered frames as a single video clip.
- **Export Profiles:** Presets for YouTube, DVD, 4K, Mobile, etc.
- **Advanced Export:** Control over bitrate, codec (H.264, H.265, VP9, AV1), and CRF.

## 8. Advanced / Experimental (2026)
- **AI & Computer Vision:** Video stabilization, motion tracking, and object detection.
- **Interactive Cropping:** Direct canvas handles for cropping footage.
- **Video Cache:** Background pre-rendering for smooth playback.
- **Auto-Recovery:** Crash protection and session restoration.
